FAQ

        

          
入力した JSON は保存されますか？

          
保存しません。ページを再読み込みすると入力・出力・エラーはすべて空に戻ります。

          
どんな JSON を整形できますか？

          
ブラウザの JSON.parse が通る標準 JSON です。末尾カンマやコメントはエラーになります。

          
エラーメッセージの位置情報とは何ですか？

          
JSON.parse が返すメッセージに含まれる位置です。どこで構文が崩れているかの目安になります。
